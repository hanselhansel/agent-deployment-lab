# Public Promotion Checklist

Complete every gate before promoting a workflow as public evidence.

## Defensible

- [ ] Claims are classified as demonstrated evidence, assumptions, or limitations.
- [ ] Evidence points to inspectable synthetic, public, or permitted inputs.

## Safe

- [ ] Inputs contain no secrets, customer identifiers, or private operational data.
- [ ] The public safety command exits successfully.

## Runnable

- [ ] A new reader can reproduce the workflow from documented commands.
- [ ] Required runtime and input assumptions are explicit.

## Tested

- [ ] Behavior tests cover the success path and fail-closed path.
- [ ] The documented test command exits successfully.

## Useful

- [ ] The buyer, problem, baseline, output, and human owner are named.
- [ ] The workflow produces an inspectable result for that stated problem.

## Shareable

- [ ] Public documentation states limitations and avoids unsupported economics claims.
- [ ] All included material is approved for public distribution.
